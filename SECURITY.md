Security Policy

Security Maintainer

@ShinyNito is the security maintainer of snell-rs and is responsible for receiving and reviewing security reports and coordinating fixes.

Supported Versions

Security fixes are provided for the latest snell-rs release. Please update to the latest release before reporting an issue.

Reporting a Vulnerability

Please report potential security vulnerabilities privately using GitHub's private vulnerability reporting feature:

https://github.com/ShinyNito/snell-rs/security/advisories/new

Please do not disclose vulnerability details in public issues or pull requests.

When reporting a vulnerability, please include:
- The affected snell-rs version or commit.
- Relevant configuration, with passwords, keys, and other secrets removed.
- Steps to reproduce the issue.
- The potential impact and any relevant logs, with sensitive information removed.
Response and Disclosure

I will review reports, communicate with the reporter, and coordinate fixes and disclosure as appropriate. Fix timelines depend on the severity and complexity of the issue.

I will credit reporters for their contributions if they wish to be acknowledged.
